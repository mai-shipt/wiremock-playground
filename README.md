# wiremock-playground
Wiremock is an open-sourced library for stubbing and mocking HTTP-based APIs.

Wiremock helps to:
* Simulate every downstream dependency locally
* Develop without needing all APIs running or relying on network
* Reproduce failures consistently (4xx, 5xx, timeout, circuit breakers, pagination errors, etc.)
* Test branching logic deterministically
